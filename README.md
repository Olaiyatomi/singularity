# Singularity

120,000 particles in one WebGL page, with no dependencies.

**Live:** https://olaiyatomi.github.io/singularity/

- **Move** the mouse to stir the field
- **Hold** to open a black hole that swallows particles
- **Release** to detonate everything it swallowed as a supernova
- **Scenes:** Flow, Galaxy, Knot (buttons, or ↑ ↓)
- **Type any word** and the particles form its letters
- **← →** change the colour palette

Open `index.html` in any modern browser to run it locally.
